1. Skenario: Masuk Akun

Use Case Name : Masuk akun UniqueID : SC-MKT-01
Area : Otentikasi
Actor(s) : Marketing
Description : Aktor melakukan proses otentikasi untuk masuk ke dalam sistem CRM.
Triggering Event : Aktor mengakses URL sistem CRM.
Trigger Type : ☒ External ☐ Temporal
Step Performed Information for Step
1. Aktor membuka halaman website CRM Sistem menampilkan halaman Login
2. Aktor memasukkan email dan password Input data kredensial
3. Aktor menekan tombol Masuk Sistem memvalidasi data ke database
4. Sistem memverifikasi kecocokan data Validasi sukses
5. Sistem mengarahkan ke halaman Beranda Menampilkan Dashboard Utama
Pre-condition : Aktor belum masuk ke sistem.
Post-condition : Aktor masuk ke dashboard utama.
Assumptions : Aktor memasukkan kredensial yang valid.
Requirement Met : Aktor berhasil masuk ke sistem.
Outstanding Issues : Kredensial tidak valid atau akun terkunci.
Priority : Tinggi
Risk : Tinggi
