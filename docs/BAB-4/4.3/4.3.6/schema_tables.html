Tabel User: Tabel untuk menyimpan data pengguna aplikasi
No Nama Field Jenis Ukuran Keterangan
1 id int 10 Primary Key, Auto Increment, Unsigned
2 name varchar 255 Nama lengkap pengguna
3 email varchar 255 Alamat email pengguna (Unique)
4 password varchar 255 Password terenkripsi (Nullable)
5 status boolean - Status aktif pengguna (Default: 0)
